# Coffee Shop Sales Forecasting Dashboard

This project focuses on forecasting coffee shop sales quantity and revenue using machine learning and time-series forecasting techniques. An interactive Streamlit dashboard was developed to visualize the forecasts and provide business insights.

## Repository Files

- **Afficionado_coffee_roasters_project_.ipynb** – Complete Google Colab notebook containing data analysis, preprocessing, feature engineering, model development, evaluation, forecasting, and insights.
- **app.py** – Streamlit dashboard application.
- **daily_quantity_forecast.csv** – Daily quantity forecast results.
- **daily_revenue_forecast.csv** – Daily revenue forecast results.
- **hourly_quantity_forecast.csv** – Hourly quantity forecast results.
- **hourly_revenue_forecast.csv** – Hourly revenue forecast results.
- **requirements.txt** – Required Python libraries for running the dashboard.
